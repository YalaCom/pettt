# Проверки версии 0.1.0

Текущая облачная машина: Python 3.12.14, Pillow 12.3.0, FFmpeg 7.1.5, Blender 4.3.2, Lupa 2.8. Фоновый Cycles-рендер на CPU и сборка H.264 MP4 проверены при настройке среды. OpenImageDenoise в установленном Blender отсутствует, шумоподавление отключено. Эти проверки инструментария не являются 3D-анимацией самого Бублика.

## Выполнено

Команды из корня репозитория:

```bash
/workspace/arizona-pet-env/bin/python tools/prepare_assets.py --all
/workspace/arizona-pet-env/bin/python tests/run.py
/workspace/arizona-pet-env/bin/python tools/preview_ui.py
/workspace/arizona-pet-env/bin/python tools/package.py
```

56 автоматических тестов прошли без пропусков. Логика реально исполнялась в LuaJIT 2.1; все Lua-файлы дополнительно разобраны Lua 5.1. Проверяются:

- ночная обида один раз, ночь со сном, короткий перезапуск, выход после полуночи, настраиваемые периоды, перевод времени назад, длительное отсутствие и ограничение штрафов;
- кормление, запасы, память еды, отказ после насыщения, блокировка ухода во сне, восстановление энергии, примирение, интервалы действий и просьб;
- магазин, уровни, рекорды, награды и история ограниченного размера;
- приоритет сна и пробуждение, окончание сильной злости, одинаковый результат временной анимации и мини-игры при 30/60/100 FPS;
- все три мини-игры, совпавшие/несовпавшие карточки, таймеры, столкновения, приз один раз;
- JSON-валидация, чтение/запись, восстановление `.bak`, архивирование испорченного основного файла, сохранение оригинала при ошибке переименования, память сна через перезапуск;
- альфа-канал, размеры холстов, отсутствие соседних пикселей в отступах атласа, точное соответствие PNG фрагментам атласа, линия лап открытой/закрытой позы, реальные PNG комнат и шрифт;
- строгий тестовый интерфейс mimgui, все комнаты, меню и мини-игры на 1920×1080, 1280×720, 800×600, 640×480; координаты без выхода за экран, баланс стеков стилей, зональное кормление, ванная в три шага, режим мини без ввода;
- жизненный цикл скрипта на **тестовых заменах** MoonLoader/SA-MP: регистрация команд, переключение окна/мини/настройки/скрытия, автосохранение, логика в скрытом режиме, сброс графического кеша и завершение;
- защитные вызовы отсутствующих/сбойных интеграций, переходы смерти и автомобиля, отключённые реакции и AFK/возвращение на тестовых API.

PNG-подготовка повторно запускалась без изменения исходников или зависимости от предыдущего результата. Рендер диагностического UI создан из фактических Lua draw-вызовов, затем визуально проверен. ZIP проверяется через `testzip()` и SHA-256 каждого включённого файла. Тестовые сохранения создаются во временном каталоге каждого запуска.

## Сверка API

Исходники `THE-FYP/mimgui` ревизии `a2fa7b1f589a2c5cb3f2aa042dd3066262cb4c90`, заявленная версия 1.7.1; генератор биндингов LuaJIT-ImGui `64cafcd6ada44ffa7d033fe32fbb5a09b3a6c043`. Сверены `OnFrame`/`OnInitialize`, `HideCursor`/`LockPlayer`, создание/освобождение текстур, `AddTextFontPtr`, `AddImage`, раздельные `PushStyleVarVec2`/`PushStyleVarFloat`, загрузка кириллического шрифта. Это чтение API и контрактные проверки, не загрузка Windows DLL в Linux.

JSON: rxi/json.lua v0.1.2, ревизия `d1e3b0f5d0f3d3493c7dadd0bb54135507fcebd7`, лицензия включена.

## Не выполнено

GTA San Andreas, MoonLoader, native mimgui/DX9 и сервер Arizona RP здесь **не запускались**. Визуальная корректность PNG проверена, но фактические FPS, объём видеопамяти, стабильность Alt+Tab, работа звуков в GTA, доступность игровых API и преобразование чата в CP1251 требуют клиентской проверки. Чеклист приведён в `GTA-CHECKLIST.md`. Автоматических интеграций заработка/майнинга нет; отсутствующие сложные клипы описаны в README.
