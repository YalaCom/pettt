# Материалы и подключение анимаций

Исходный репозиторий был пустым, без предыдущих скриптов и коммитов. Пользователь предоставил ТЗ и изображение с четырьмя ракурсами Бублика; локального PNG-файла этого вложения инструмент скачивания не предоставил. Оно использовано как визуальный референс при генерации. Локальные исходники новых PNG находятся в `assets/source/`; исходная картинка пользователя не выдается за эти новые материалы.

Три изображения Бублика изготовлены генератором изображений по референсу: открытые глаза, закрытые глаза, обиженная мордочка. Закрытые глаза и обида получены редактированием первой позы с сохранением композиции. Это предварительно подготовленные 2D-ресурсы; наличие 3D-модели не заявляется. Пять комнат и альтернативная гостиная сгенерированы как шесть отдельных панелей одной сетки. Обрезка фонов по точной сетке не используется для разделения соприкасающихся персонажей.

## Подготовка

```bash
python tools/prepare_assets.py --all
```

`assets/frames.json` содержит **явные** координаты опорной точки каждого исходника и **единый** коэффициент масштаба 0.39. Инструмент не вычисляет новый масштаб и новый центр отдельно по альфа-границам каждого кадра. Общий холст 512×512, якорь (256, 480). Почти невидимый фоновый шум с альфой 1–2 удаляется; настоящая полупрозрачная шерсть сохраняется. У готовых поз линия лап совпадает с допуском в один пиксель растеризации, исходные позы имеют небольшие различия в шерсти; точность полноценного рига не заявляется.

Проверяется прозрачность, связные компоненты, касание границы обрезки, выход персонажа за холст, одинаковые ID и консервативный максимум атласа 2048. Значимые раздельные компоненты могут означать соседних персонажей: инструмент отклоняет такую запись. Если два персонажа соединены в один компонент внутри одного кадра, автоматическая сегментация не гарантируется: нужны явные корректные маски/новые исходники и визуальная проверка. Касание края намеренной позой можно отдельно разрешить `allow_border_touch`, принимая ответственность за исходник. Не используйте этот флаг для маскировки захвата соседнего кадра.

Для работы со спрайт-листом можно задать `rect: [left, top, right, bottom]`; координаты `anchor` в таком случае относятся к локальной обрезке. Обрезка, на границе которой остаётся значимая альфа, по умолчанию отклоняется. Если оригинал не содержит нужных пикселей, инструмент их не восстанавливает.

Результаты: отдельные RGBA PNG, атлас с двухпиксельными прозрачными отступами и размерами по степени двойки для старых устройств DX9, JSON-диагностика, `animation/frames.lua`, диагностический GIF моргания. UI использует UV, смещённые на половину текселя внутрь содержимого кадра; исходные безопасные прозрачные поля обеспечивают защиту края при линейной фильтрации.

## Новые клипы

Добавьте реально изготовленные кадры в `assets/frames.json`, сохраняя общие масштабы и опорную систему. Пересоберите атлас. В `moonloader/lib/arizona_pet/animation/catalog.lua` добавьте запись:

```lua
happy = {
    frames = {{'happy_start', 0.10}, {'happy_main', 0.08}, {'happy_end', 0.12}},
    priority = 40,
    next = 'idle',
}
```

Это пример формата, а не существующие имена кадров. Модули UI и потребностей менять не нужно. Состояние `sleep` имеет приоритет 100 и не перебивается морганием. `wake` имеет 101; сильная злость заканчивается состоянием `offended`. Удалите `fallback=true` лишь после появления и проверки полноценного клипа. Не добавляйте копии одного PNG ради заявленного числа кадров. Для больших библиотек понадобится расширение инструмента на несколько страниц атласа; сейчас большой атлас отклоняется.

UI-файлы — настоящие используемые текстуры кнопок и значков. Шесть объёмных значков сгенерированы отдельным прозрачным листом 3×2: яблоко, луна, шампунь, мяч, лента с сердцем и монеты. После проверки прозрачных границ нарезаны в PNG 64×64; символы и буквы не заменяют эти изображения. Шрифт Open Sans сопровождается исходной лицензией из Debian. JSON-библиотека rxi/json.lua v0.1.2 распространяется по MIT. Шесть WAV — короткие синтезированные уведомления собственной генерации, не записи голоса животного.
