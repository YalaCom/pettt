# ARIZONA PET · Бублик

Версия 0.1.0 — модульная игра-питомец для **GTA San Andreas / SA-MP / MoonLoader / mimgui**, без браузера. Исходники и PNG действительно находятся в этом репозитории. Клиент GTA в облаке отсутствует: совместимость с конкретной сборкой Arizona RP нужно подтвердить на игровом компьютере. Это первая реализация, а не заявление о полном выполнении всей библиотеки анимаций из ТЗ.

## Установка в GTA

**Важно для исправления запуска:** архив `dist/ARIZONA-PET-0.1.0.zip` собран до изменения загрузчика, поэтому временно содержит старую версию `arizona_pet.lua`. Пока установочный ZIP не пересобран, скачайте **исходники ветки с исправлением** через GitHub → Code → Download ZIP. Внутри архива откройте папку `moonloader` и **скопируйте всё её содержимое** в папку `bin/arizona/moonloader/` вашей GTA. Убедитесь, что файлы действительно лежат по путям:

- `bin/arizona/moonloader/arizona_pet.lua`
- `bin/arizona/moonloader/lib/arizona_pet/core/state.lua`
- `bin/arizona/moonloader/resource/arizona_pet/pet/atlas.png`

Не создавайте лишнюю вложенную папку `moonloader/moonloader/`. Если после установки команда `/pet` неизвестна, проверьте наличие `arizona_pet.lua` по указанному пути и пришлите файл `bin/arizona/moonloader/moonloader.log`. Если есть ошибка загрузки `mimgui` или модулей питомца, исправленная версия сообщит об этом через `/pet`, когда сам Lua-файл находится в нужном месте.

1. Нужны MoonLoader **0.26**, SA-MP и **mimgui 1.7.1** с нативными DLL, соответствующими клиенту. Ссылки: [MoonLoader](https://www.blast.hk/threads/13305/), [mimgui](https://github.com/THE-FYP/mimgui). Установка старого `imgui` вместо `mimgui` не подходит. `encoding` обычно входит в комплект MoonLoader.
2. Распакуйте `ARIZONA-PET-0.1.0.zip` в папку GTA, объединив папку `moonloader` с существующей. Или скопируйте содержимое `moonloader/` из репозитория. Файл запуска: `moonloader/arizona_pet.lua`; модули: `moonloader/lib/arizona_pet/`; изображения, шрифт и звуки: `moonloader/resource/arizona_pet/`.
3. Запустите GTA и зайдите в SA-MP. Введите `/pet`. Не ставьте две копии скрипта одновременно.
4. Пройдите [проверку в клиенте](docs/GTA-CHECKLIST.md). Ошибки и отсутствующие файлы выводятся в `moonloader.log` и, когда возможно, в чат.

Python, Pillow, FFmpeg и Blender нужны **только разработчику**, для подготовки материалов. Пользователю GTA они не нужны. MoonLoader/mimgui и GTA не включены в ZIP.

## Команды

| Команда | Действие |
|---|---|
| `/pet` | Открыть / закрыть большую панель |
| `/petmini` | Показать / скрыть мини-питомца |
| `/petedit` | Режим настройки мини-питомца: перетаскивание, поглаживание головы, открытие панели нажатием на тело; повторная команда выключает захват ввода |
| `/pethide` | Скрыть всё и отключить интерактивный режим, продолжая логику потребностей |
| `/petsave` | Сохранить прогресс вручную |

По умолчанию мини-питомец выключен. В обычном мини-режиме используются `NoInputs`, `HideCursor=true`, `LockPlayer=false`; мышь и управление GTA не запрашиваются. Положение внизу справа является стартовым вариантом, а не гарантией отсутствия пересечений с модами HUD: настройте его через `/petedit`.

## Реализовано

- Бублик из настоящих PNG с прозрачностью, три уникальные позы: спокойная, закрытые глаза, обида. Моргание, сон, ласка и выражение обиды используют эти позы. Дыхание — небольшая процедурная деформация вокруг стабильной линии лап. В мини-игре прыжки перемещается этот же PNG.
- Воспроизведение по времени, длительности кадров, приоритет сна, переходы с коротким смешиванием, общий масштаб и якорь, безопасные UV и прозрачные отступы. Текстуры кешируются, лишние освобождаются между кадрами, кеш сбрасывается при потере устройства Direct3D.
- Русская панель со шрифтом Open Sans и пятью графическими комнатами; шестой фон — покупной вариант гостиной. Главное окно без прокрутки, масштабируется под экран.
- Шесть потребностей, кормление тремя продуктами, любимая еда по истории кормлений, ласка по зоне головы и движению мыши, сон/пробуждение, ванная в три шага, игра с игрушкой.
- Память, характер, история событий, привязанность, просьбы с ограничением частоты, подарки за заботу, реакция после длительного отсутствия, примирение и ночная обида.
- Уровни, опыт, внутренние монеты, магазин, три достижения, декоративная лента, второй интерьер. Возрастные стадии внешности не изготовлены.
- Три мини-игры: «Лови еду» (мышь, 30 секунд), «Прыжки» (нажатие в игровом поле, 30 секунд или столкновение), «Найди пару» (12 карточек, максимум 180 секунд). Результаты сохраняются, награда выдаётся один раз. Незавершённая игра отменяется при уходе из неё.
- JSON-сохранения: временный файл, повторная проверка данных, резервная копия, восстановление из `.bak`, архив повреждённого файла. Автосохранение каждые 30 секунд и сохранение при завершении скрипта. При жёстком падении теряется максимум последний несохранённый отрезок; гарантия `fsync`/атомарной замены Windows здесь не заявляется.
- Отдельный профиль по адресу сервера и имени персонажа, когда доступны соответствующие SA-MP функции; иначе `default`. Пароли, токены и координаты персонажа не сохраняются.
- Опциональные короткие синтезированные звуковые уведомления, громкость и отключение. Это не голосовые записи питомца. Без аудио-API скрипт продолжает работу без звука.
- Модули безопасного чтения состояния смерти, автомобиля и игровых часов; эвристика неактивности по движению и выборке клавиш. Каждый вызов проверяется на существование и защищён `pcall`.

## Ночная память

Используется **локальное время компьютера**, а не часы сервера GTA. По умолчанию ночь 21:00–05:00, утро 05:00–12:00. Периоды находятся в `settings` файла сохранения. Выход в ночной период без сна, отсутствие не менее двух часов и возвращение утром вызывают обиду один раз при загрузке профиля, не при открытии панели. Первые пять секунд питомец отказывается от ласки; затем забота сокращает обиду. После правильно организованного сна — доброе утро и восстановление энергии.

Офлайн-ухудшение ограничено шестью часами. Здоровье не падает ниже 20, после отсутствия состояние остаётся восстановимым. Перевод часов назад не приводит к отрицательному офлайн-времени или дополнительным штрафам. При аварийном завершении используется последнее автосохранение как приближение момента выхода.

## Что ещё требует материалов или проверки

- Нет готовых отдельных кадров жевания, танца, поворота головы, отворачивания, скрещивания лап, купания, радостного прыжка, смеха и остальных сложных движений из ТЗ. Эти состояния объявлены в `animation/catalog.lua` с явной пометкой `fallback`; некоторые эффекты и эмоциональные реплики реализованы, но не заменяют настоящую анимацию. Пока доступны три позы, а не десятки клипов.
- Референс не является 3D-моделью. Модель, скелет и рендер-пайплайн анимаций персонажа не изготовлены. Blender доступен в облаке для будущей работы, но PNG этой версии подготовлены из сгенерированных по референсу изображений.
- Реакции на заработок, траты и майнинг **не подключены к Arizona**. Изменение баланса само по себе не доказывает заработок, а примеров подтверждённых сообщений сервера не предоставлено. В `integration/game.lua` есть `confirmed_economy(kind, amount, source)` для будущего проверенного адаптера. Нет хуков сетевых пакетов, автоклика, фарма или автоматизации персонажа.
- Смерть/автомобиль/часы и неактивность проверены на тестовых API, а не в GTA. Эвристика AFK не распознаёт все способы общения, мышь и геймпад; она не является статусом AFK сервера.
- DirectX 9, Alt+Tab, реальная кириллица в чате, освобождение курсора и производительность на ПК требуют клиентских проверок. Синтаксические и автономные проверки этого не доказывают.

## Разработка в облаке

Используйте текущий checkout `/workspace/pettt`; отдельный Git worktree не нужен, если его специально не запросили.

```bash
cd /workspace/pettt
source /workspace/arizona-pet-env/bin/activate
python -m pip install --no-cache-dir -r tools/requirements.txt
python tools/prepare_assets.py --all
python tests/run.py
python tools/preview_ui.py
python tools/package.py
```

`tests/run.py` исполняет Lua-модули в LuaJIT 2.1 через Lupa, дополнительно проверяет весь Lua-синтаксис интерпретатором Lua 5.1 и проверяет PNG. UI-тесты используют строго ограниченные замены API; `test-output/ui-diagnostic.png` — растеризация фактических draw-вызовов Lua, **не скриншот из GTA**. Автономный просмотр анимации: `moonloader/resource/arizona_pet/pet/diagnostic.gif` (шахматный фон и красная линия только в диагностике).

Сохранения находятся в `moonloader/config/arizona_pet/`, не включены в ZIP и Git. Техническое описание графики: [ASSETS.md](docs/ASSETS.md). Проверенные версии и результаты: [VALIDATION.md](docs/VALIDATION.md).
